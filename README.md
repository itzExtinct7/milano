# Vinster Multipurpose Bot — GitHub Pages legal site

Static website containing the Privacy Policy and Terms of Service.

## Before publishing
1. Open `privacy.html` and `terms.html`.
2. Replace the contact placeholder with a monitored support email or public support-server invite.
3. Confirm your actual host access, backup rotation/deletion schedule, operational log retention and third-party provider configuration. The current bot code creates database backups but does not define a finite backup retention schedule.
4. Review the documents for your jurisdiction and actual operating practices. These templates are not legal advice.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `vinster-bot-legal`.
2. Upload the contents of this folder (not the enclosing folder) to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
4. Wait for the Pages deployment to finish. Your pages will be available at:
   - `https://YOUR-GITHUB-USERNAME.github.io/vinster-bot-legal/`
   - `https://YOUR-GITHUB-USERNAME.github.io/vinster-bot-legal/privacy.html`
   - `https://YOUR-GITHUB-USERNAME.github.io/vinster-bot-legal/terms.html`

A GitHub Pages custom domain is optional. Use the exact published Privacy Policy URL in Discord's application form.
